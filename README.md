# 安靜一下 — 測試版3

基於 V2.1，保留「我現在很難受」以及原有功能。

## 本版新增

1. 讓我做點別的
   - 隨機低難度找東西任務。
   - 每完成一個可以立即換下一個。

2. 身體鬆一點
   - 一次只顯示一個小動作。
   - 包括下頜、舌頭、肩膀、手指、腹部、腳趾等。

3. 呼吸優化
   - 預設自動跟著節奏。
   - 預設改成「吸 4 秒 / 呼 6 秒」。
   - 不再要求停留。
   - 畫面只顯示「吸氣 / 慢慢呼氣」，不顯示倒數數字。
   - 仍可隨時點「不想跟著節奏」。

4. 看著它走一會兒
   - 緩慢視覺追蹤。
   - 不需要做題，也不用控制呼吸。

5. 聽一會兒
   - 鳥叫森林
   - 雨聲
   - 木柴燃燒
   - 風吹樹林
   - 四段都是本測試版打包的短循環 WAV，不依賴外部網站。

## 離線音頻

`audio/` 中包含：
- `forest_birds.wav`
- `rain.wav`
- `fireplace.wav`
- `wind_trees.wav`

`service-worker.js` 會把四段聲音和主頁檔案一併快取。首次在線成功載入本版後，後續可離線循環播放。

## 上傳 GitHub 測試分支

把 ZIP 解壓，將裡面的所有檔案放到 `Emotional` repository 的測試分支根目錄，覆蓋舊版後 Commit / Push。

你的 GitHub Pages 如果已經指向該測試分支，部署完成後重新打開 iPhone 主畫面 App 即可更新。
